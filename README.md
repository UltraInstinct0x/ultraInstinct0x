# Hi, I'm Gokhan, I go by Goku 👋

I build things for myself first: agent infrastructure, local-first AI tooling, and small utilities that fix a specific annoyance. I live in Izmir and work as a CRM Analyst, and most of my time outside that goes into self-hosted systems and the tools around them.

## What I work on

- **Agent infrastructure and observability**: capturing what an agent actually did, including model I/O, tool calls, and human feedback loops. Mostly plumbing in the form of proxies, collectors, SDKs, plugins, and hooks.
- **Privacy-aware data handling**: redacting PII and secrets before they leave a process, with EUR/TR rule packs and reversible token mapping.
- **Local-first and self-hosted software**: my own machines run the stack, so I care about things that work offline, survive restarts, and do not need a vendor.
- **Media and voice tooling**: transcription, dubbing, and speech pipelines, including Turkish-language work.
